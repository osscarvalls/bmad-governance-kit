# Agent TODO — pending agent work

> **What this is.** The twin of [`HUMAN-TODO.md`](HUMAN-TODO.md): the single index of pending **agent work**
> — agreed follow-ups that didn't fit the session they were born in. Maintained by the agent; the human
> reads it to see the queue without asking.
>
> **Entry rule.** An item belongs here **only if it is agent-actionable AND was explicitly agreed** (not
> stray ideas). Anything that needs a human goes to `HUMAN-TODO.md`.
>
> **Item format.** `What · Context · Unblocked-by`.
> **Lifecycle — this is NOT a log.** When an item completes it is **deleted**; the result lives in its
> destination artifact. Do not accumulate history here.
>
> **States:** 🟢 ready (needs a session/time) · 🟡 blocked by other work · ⚪ waiting on external input.
